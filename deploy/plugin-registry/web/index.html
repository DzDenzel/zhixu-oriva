签名证书 SHA-256 信任锚指纹
  1. 在手机打开知序 设置 → 插件，阅读风险说明后关闭「安全模式」。
  2. 点击 自定义第三方来源 → 添加来源，填入来源名称、上方复制的「目录 JSON 地址」与「来源 ID」。
  3. 粘贴「信任锚指纹」完成绑定；未绑定指纹时仅可发现浏览，客户端绝不会跳过 JAR 签名校验。

安全说明：第三方插件与知序运行在同一进程，项目不审核、不背书或保证任何第三方插件；安装时客户端仍强制核验文件 SHA-256 与签名证书指纹。
